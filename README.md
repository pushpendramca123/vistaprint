# VistaPrint homepage recreation

Open index.html directly, or start Apache in XAMPP and visit http://localhost/vistaprint/.

HTML, CSS, Bootstrap 5.3.3 and vanilla JavaScript. Bootstrap and images are local. Includes responsive layouts, product sliders, mobile navigation, search, discount code copy and Bootstrap dialogs.

Product links open VistaPrint. Account, cart and newsletter are frontend previews without a backend. Newsletter image is an approximate card collage. Images and branding come from the supplied VistaPrint reference.
